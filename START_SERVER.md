# Start the Tic Tac Toe server (beginner friendly)

1. **Install Node.js 18+** if you do not have it yet. On most systems you can download it from [nodejs.org](https://nodejs.org/) and run the installer.
2. Open a terminal and change into this project folder:
   ```bash
   cd /workspace/emuvex
   ```
3. Run the server with plain Node:
   ```bash
   node server.js
   ```
   The server starts on **http://localhost:3000** and serves the lobby UI.
4. Open your browser to `http://localhost:3000`.
5. Pick a username, create or join a lobby, and start playing.

If you need to stop the server, press **Ctrl+C** in the terminal.
